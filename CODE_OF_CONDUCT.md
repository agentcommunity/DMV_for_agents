# Code of Conduct

## The short version

Be kind. Be respectful. Assume good intent. We're building infrastructure for agents — let's be better than the DMV's reputation.

## The longer version

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) (v2.1). In summary:

- Use welcoming and inclusive language
- Respect differing viewpoints and experiences
- Accept constructive criticism gracefully
- Focus on what's best for the community

## Scope

This applies to all project spaces — issues, PRs, discussions, and any public space where you represent the project.

## Enforcement

Instances of unacceptable behavior can be reported to the project maintainers at [agentcommunity.org](https://agentcommunity.org). All reports will be reviewed and investigated.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
